## ⚡ Getting Started
Clone the repo and get started in just a few simple steps.

### Prerequisites
Ensure you have the following installed:
- **Node.js** (v14+)
- **npm** (v6+)

### Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/fahrurojak/fahru-portofolio.git
   cd my-portfolio
   ```

2. **Install the dependencies:**
   ```bash
   npm install
   ```

## 🚀 Running the Project
Launch the development server to explore the portfolio locally:

```bash
npm run dev
```

The Vite development server will start. Open [http://localhost:3000](http://localhost:3000) in your browser and watch the magic unfold.
